## Part B 机制速查

### B1. 链执行
一条链由 `GraphChainRunner.RunChain` 驱动：`Execute()`（期间 `NodeExecuteContext.Current = 宿主`）→ `yield GetFlow()`（等待/插值/循环等）→ `GetConnectedNode()` 步进；上限 100 步防死循环。主链（GraphExecutor）与子图链、循环体链共用同一执行器，行为一致。

### B2. 触发与策略
- 每次触发启动一条链（协程），同起点按 `triggerPolicy`：Restart（停旧重跑）/ IgnoreWhileRunning（运行中忽略）/ Queue（排队再跑）；不同起点并发。
- `executeInterval` 每链步进间隔；`executeCount`（0=无限）按链计数。
- 入口事件订阅：`CurrentEntry`（只监听自己入口）/ `AllEntries`（按 eventId 解析入口）。

### B3. 统一图调用参数（核心）
- 存储：图资产内 `invocationParams`（非序列化，不进存档/变量包/编辑器下拉）。
- **四路注入**：`SubGraphNode`（父图连线）/ `ExecuteFromEntry(entryId, args)` / `GraphEvent.data` / `TransitionTo(state, args)`。
- **读取**：图内用「参数/输入/…」节点（`paramName` 对应键，未命中回退图变量→节点字段）；返回值用「参数/输出/…」节点。
- **外部读回**：`graph.GetOutputValue<T>(paramName)` / `executor.GetOutput<T>(paramName)`。
- **替换语义**：每次带参触发先清空上一批再注入；`ClearInvocationParams()` 主动清空。

### B4. 子图
`SubGraphNode` 按子图内「参数/输入|输出」节点自动生成动态端口（端口名=参数名）；执行时父图连线值→子图调用参数存储→跑子图链（同步阻塞）→读回输出；嵌套深度上限 8；`resetVariablesOnCall` 重置子图变量（调用参数每次调用重新注入不受影响）。

### B5. 状态机
`GraphStateMachine` 状态=子图；`TransitionTo` 停当前链+起新链；链宿主=状态机自身（子图/操作节点 Attached 目标=状态机物体）；`subscribeEntries` 订阅当前状态子图入口事件；`loop` 链跑完循环重跑。

### B6. 变量与存档
- `VariableBundle` 类型容器：string/bool/int/float/Vector2/Vector3 + 五种 List；名字+GUID 双向映射兜底改名。
- 作用域：图内（Self）/ 跨图（ExternalGraph，按图名）/ 房间 / 全局（持久，`persist` 开关）。
- 存档：以图 GUID 为键；房间+全局两层（staging→archive）；`VariableBundleData` 序列化含列表与 Vector2。

### B7. 外部 Input 传参
外部脚本声明 `public GraphParamList input;`（Inspector 可视化编辑参数）→ 运行时 `input.Build()` → `executor.ExecuteFromEntry("OnInput", p)`（或 `GraphParamEmitter.Emit()` 走事件）；图内「参数/输入」节点读取；参数名必须与图内 `paramName` 一致。

### B8. 组件动作目标解析
`ComponentActionNode<T>` 子类（变换/刚体/音频/动画/相机等）：`targetGameObject` 输入端口（接「取值/获取物体」）优先 → 否则 `target` 模式：Attached（图绑定物体）/ ByName（子物体名）/ Direct（拖引用）。

## 附：常见组合示例

- **Input 驱动移动**：外部 `GraphParamList{move:Vector2}` → `ExecuteFromEntry("OnInput")` → 「参数/输入/Vector2」→ `刚体/设置速度(2D)`。
- **对话镜头**：事件"进入对话" → `相机/虚拟相机优先级`（对话特写 vcam）+ `相机/设置注视`（NPC）→ 「插值/透明度」淡入对话框。
- **过场**：`流程/并行`（角色 `插值/移动到` ∥ `相机/轨道速度`）→ 结束后 `流程/跳转到入口` 回玩法。
- **遍历物品**：`流程/遍历列表/字符串`（列表变量）→ 每项 `列表/是否包含` 判断 → `流程/分支`。
